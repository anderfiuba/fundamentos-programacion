# Programming Practice Exercises

This repository contains programming exercises created to practice and prepare for university exams.

The main goal is to improve problem-solving skills, reinforce programming concepts, and review topics covered in class through practical exercises.

## Topics

The exercises may include:

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists and dictionaries
- File handling
- CSV files
- Error handling
- Basic problem-solving exercises

## Purpose

This repository is mainly used as a study and practice space for university exams.  
The exercises are organized to help review concepts, practice different types of problems, and improve programming skills over time.
